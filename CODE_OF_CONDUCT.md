# Davranış kuralları

Bu proje [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) davranış kurallarını benimser.

Kısaca: herkese saygılı davran, kişisel saldırı ve taciz yapma, başkalarının kişisel bilgilerini izinsiz paylaşma.

Kural ihlallerini proje sahibine GitHub üzerinden özel olarak bildirebilirsin. Bildirimler gizli tutulur.
